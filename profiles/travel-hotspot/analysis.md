# 评估目标

评估一条过去 24 小时内出现的内容，是否值得进入《24小时旅游热点》的**候选池**。这是候选排序，不是最终发布审核。评分范围 0-10 分。

# 评分标准

- **9.0-10.0：全国级强热点。** 大范围影响游客决策的政策、交通、景区变化；跨区域明显发酵的目的地/玩法；强传播性且事实清晰的重要旅游事件。
- **8.0-8.9：强候选。** 明显新鲜、有具体事件，对大量游客有较强价值或传播潜力；长三角/安徽的重要热点也可进入此档。
- **7.0-7.9：优质候选。** 能明显影响去哪、何时去、怎么玩、路线安排、预约、费用或避坑，或具备较强的话题性。
- **6.0-6.9：正常候选。** 事件具体、新鲜，对部分游客或某一地区有明确实用价值，但影响范围或传播强度一般。
- **5.0-5.9：备选候选。** 确有新的旅游事件/变化/现象，但全国传播性较弱，适合作为候选池补充。
- **3.0-4.9：低价值。** 常规资讯、一般攻略、普通政务宣传、普通促销、重复报道，或游客价值较弱。
- **0-2.9：噪音。** 广告、标题党、无事实支撑、与旅游无关、纯营销、明显旧闻或搜索误命中。

不要把大量“真实但普通”的旅游新闻全部压到同一个低分段。只要是过去24小时内的具体新事件，并且对游客有明确价值，应在 5-7 分之间拉开差异；真正无游客价值的内容再给低分。

# 判断维度

综合考虑以下因素，不要求机械逐项算分，但最终分数应体现这些权重：

1. **真实事件与事实明确度（25%）**：必须有清楚的新事件、新变化或新现象，不能只有情绪化标题。
2. **传播潜力（25%）**：普通游客是否会停下来、讨论、转发或产生出游兴趣。
3. **旅游决策价值（20%）**：是否影响去哪、什么时候去、怎么玩、路线安排、时间成本、费用或规则。
4. **新鲜度（15%）**：过去 24 小时内的新内容优先；旧事件换标题重发应降分。
5. **地域价值（10%）**：安徽、江苏、浙江、上海、南京、合肥、滁州及长三角周边，在同等质量下适当加分，但不能因为地域近就放宽真实性标准。
6. **二次实用信息潜力（5%）**：能否继续挖出点位、时段、交通、预约、玩法组合、时间成本、适合人群等“新中小贴士”。

# 硬性降分规则

- 单纯“门票降价、套餐优惠、低价促销”不得仅凭便宜进入高分档；除非已经形成明显热点或带来重要游客决策变化。
- 常规节庆预告、政务宣传、招商活动，如没有具体游客价值，最高 4.9 分。
- 只有媒体转载、没有原始事实或无法确认具体发生了什么，应明显降分。
- 同一事件的重复报道不应因为媒体数量多而重复获得高分。
- 不得把“可能会火”“预计爆满”等推测当成已发生事实。
- 与旅游无关、语言明显异常、搜索误命中的内容直接按噪音处理。

# 输出压缩要求

为降低长期调用成本，只输出完成判断所需的信息：

- `reason`：一句话，尽量控制在 45 个汉字内。
- `summary`：一句话，尽量控制在 60 个汉字内，只写核心事实。
- `tags`：2-4 个具体标签，优先使用目的地、事件类型、客群或玩法标签。
